# 第 47 轮：sparse 新发现 M251–M254 在 d 精度下的复核

程序：`probes/round47_dsparse.cpp`（magma_d* 接口），每项检查单独一个进程（`dsparse.txt`）。

| 发现 | d 精度结果 |
|---|---|
| M252（CSR→COO 行下标字段不一致） | 复现：[1 0 2; 0 3 0; 4 0 5] 往返后行指针为 [0 5 5 5]，最大误差 5 |
| M254（CSRLIST 空行越界） | 复现：第 0 行为空时，往返输出 38 个非零元（输入 37 个），误差 2；随后在释放内存时访问违例（0xC0000005），堆已损坏 |
| M253（ELLRT 归约竞争） | 复现：dgeellrtmv 第 5 行结果为 62.495，应为 87.34（与 z 精度丢失的线程完全相同） |
| M251（SELL-P 参数丢失） | 复现：magma_dmconvert(设备 CSR→SELLP) 整数除零崩溃（0xC0000094） |

结论：这 4 条在 z 和 d 两种精度下都已在 GPU 上证实。s/c 精度由同一模板生成，未单独实测。
